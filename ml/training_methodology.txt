Training Methodology
====================

The classifier was implemented as a sequential convolutional neural network (CNN) using TensorFlow/Keras and trained to perform binary classification on continuous wavelet transform (CWT) scalogram images. Each input image has dimensions of 256 x 100 pixels, with one or more channels corresponding to different photodiode signal sources. The convolutional backbone follows a VGG-block pattern, consisting of stacked Conv2D layers with 3x3 kernels and ReLU activations, grouped in pairs of equal filter count (default: [16, 16, 32, 32, 64, 64]); a 2x2 max-pooling operation is inserted after each transition between filter-count groups. The convolutional layers are optionally followed by batch normalisation and spatial dropout. The flattened feature maps are passed through one or more fully connected layers (default: 128 units, ReLU) with dropout regularisation, before a single sigmoid output neuron produces the binary class probability. L2 weight regularisation (lambda = 0.001) is applied throughout the convolutional and dense layers to reduce overfitting. The network is compiled with the Adam optimiser (default learning rate 5e-4) and binary cross-entropy loss. Model performance is evaluated using accuracy, precision, recall, and F1-score. To provide a robust estimate of generalisation, training is conducted under stratified k-fold cross-validation (k = 5), ensuring class balance is preserved across folds. Within each fold, the training set is normalised and optionally augmented via temporal shifting, additive Gaussian noise, or brightness and contrast perturbation applied to a random subset of samples. Class-weighted loss is used by default to compensate for any class imbalance in the dataset, with weights computed analytically from the training fold label distribution. Training runs for a maximum of 50 epochs with two adaptive callbacks: (1) early stopping (patience = 10 epochs) monitoring validation accuracy and restoring the best-weight checkpoint, and (2) learning rate reduction on plateau (patience = 5 epochs, reduction factor = 0.5, minimum learning rate = 1e-7). The best model checkpoint from each fold is retained. Following training, gradient-weighted class activation mapping (Grad-CAM) is applied to the final convolutional layer to produce saliency heatmaps that indicate which time-frequency regions of the CWT scalogram are most discriminative for the model's predictions.
